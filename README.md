## What I've Shipped

### Terriva
[![Live Site](https://img.shields.io/badge/Live_Site-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://terriva.vercel.app/) [![GitHub Repo](https://img.shields.io/badge/GitHub_Repo-000000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Shivamkhator/Terriva)

Terriva is a menstrual-health Progressive Web App that helps users track their cycles and understand them through personalized, AI-generated insights.
- Built a RAG assistant that grounds Google Gemini's answers in each user's own cycle history, so the insights are specific to them rather than generic.
- Users log daily flow, manage period history, and view an insights dashboard with charts generated from their own data. PostgreSQL analytics predict upcoming cycles.
- Automated email reminders run on scheduled cron jobs over SMTP.
- Sign-in is fully passwordless with NextAuth: email magic link, Google OAuth and WebAuthn passkeys.
- Installable as a PWA with an app-like UI built with Shadcn UI and Framer Motion.

**Stack:** Next.js, PostgreSQL, Google Gemini, NextAuth

### SkyBee Routes
[![Live Site](https://img.shields.io/badge/Live_Site-000000?style=for-the-badge&logo=render&logoColor=white)](https://skybee-routes.onrender.com/) [![GitHub Repo](https://img.shields.io/badge/GitHub_Repo-000000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Shivamkhator/SkyBee_Routes)

SkyBee Routes is a Django web app that computes optimal flight routes across a network of 9,000+ airports and 90,000+ routes.
- Modeled the global airport network as a NetworkX graph and implemented A*, Dijkstra and Q-learning route search, comparing the algorithms' performance, with centrality analysis to identify key hubs.
- Integrated live flight deals from the Amadeus API and AI-powered price suggestions from Google Gemini.
- Visualized routes on interactive Folium maps, with a Tailwind CSS interface.
- Containerized with Docker and deployed on Render.

**Stack:** Django, NetworkX, Pandas, Amadeus API, Google Gemini, Docker
